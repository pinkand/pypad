# PyPad 开发宪法

## 核心使命

PyPad 是 AI 驱动的 Python Learning OS。所有开发必须服务于核心闭环：

```text
教材 ➔ 知识 ➔ 关系 ➔ 路径 ➔ 学习 ➔ 编程 ➔ 练习 ➔ AI反馈 ➔ 掌握度 ➔ 下一步
```

## 唯一事实来源

`PROJECT.md`、`ROADMAP.md`、`ACCEPTANCE.md`、`ARCHITECTURE.md`。代码与文档冲突时优先遵循文档。

## 铁律

1. **禁止假完成**：不写假 API、不硬编码 JSON、不用 Mock 冒充、不用 TODO 占位
2. **范围纪律**：只解决当前任务，不擅自扩展，不降低需求
3. **完成定义**：实现 + 集成 + 测试 + 错误处理 + 文档 + 验收 + E2E 全部通过才能标 DONE
4. **变更控制**：发现冲突先报告，未经确认不改架构
5. **事实原则**：AI 是事实解释者而非决定者，无证据标 UNKNOWN

## 优先级

P0 核心闭环 > P1 业务功能 > P2 基础设施 > P3 测试 > P4 UI > P5 扩展
