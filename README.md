# PyPad — AI-Powered Python Learning OS

AI 驱动的 Python 学习操作系统。

## 项目结构

```
PyPad/
├── pypad-frontend/    # 前端 (Vue 3 + Vite + Tailwind + Monaco Editor + Three.js)
├── pypad-backend/     # 后端 (Python FastAPI + SQLModel + Qdrant)
├── tests/             # 测试 (API 24项 + E2E 48项)
├── docs/              # 文档
└── docker-compose.yml
```

## 快速开始

```bash
# 后端
cd pypad-backend && python main.py

# 前端
cd pypad-frontend && npm install && npm run dev
```
