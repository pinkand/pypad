# PyPad 参赛材料

## 项目信息

- **作品名称**: PyPad
- **项目名称**: PyPad
- **产品定位**: AI 驱动的 Python 学习操作系统
- **英文全称**: PyPad — AI-Powered Python Learning OS

## 源代码目录

- 前端项目: `pypad-frontend/`
- 后端项目: `pypad-backend/`

## 技术架构

### 前端 (pypad-frontend)

- Vue 3 + TypeScript
- Vite 构建工具
- Tailwind CSS 样式框架
- Monaco Editor 代码编辑器
- Three.js 3D 可视化

### 后端 (pypad-backend)

- Python FastAPI
- SQLModel ORM
- MySQL 数据库
- OpenAI/Ollama AI 集成

## 核心功能

1. **智能知识图谱** - 可视化 Python 知识点关联
2. **AI 代码审查** - 智能代码质量评估
3. **个性化学习路径** - 基于掌握度的自适应学习
4. **实时代码执行** - 在线 Python 运行环境
5. **多 Agent 协作** - 导师、规划师、编码教练等 AI 角色
